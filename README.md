# spotify-chart-analysis

Overview: An exploratory data analysis of the Spotify Top 50 USA chart using SQL and Excel to uncover trends in artist performance, collaborations, and content type.

Tools Used: SQLite, VS Code, Microsoft Excel

Questions Explored: Which artists appeared most frequently on the Spotify Top 50 USA chart? Do collaborations chart higher than solo artists? Does explicit content affect chart performance?

Key Findings: Taylor Swift had the most chart appearances by a significant margin. Collaborations chart slightly higher on average than solo artists, though the difference is modest. Explicit and non-explicit songs perform nearly identically on the charts.
